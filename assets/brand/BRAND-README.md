# Cue brand kit

## Included
- `cue-icon-dark.svg` — primary app icon, dark tile
- `cue-icon-light.svg` — light tile variant
- `cue-icon-accent.svg` — accent tile variant
- `cue-mark-transparent.svg` — standalone mark, dark stroke
- `cue-mark-white-transparent.svg` — standalone mark, light stroke
- `cue-wordmark.svg` — horizontal transparent wordmark for light backgrounds
- `cue-wordmark-dark-background.svg` — horizontal transparent wordmark for dark backgrounds
- `cue-theme.css` — CSS custom properties and light/dark theme mapping
- `cue-palette.json` — palette and basic design tokens

## Brand colors
| Token | Hex | Use |
|---|---|---|
| Ink | `#171817` | Main dark background, text |
| Surface | `#F1F0EC` | Light background, light logo stroke |
| Accent | `#A8E66B` | Cue dot, active state, primary highlight |
| Accent light | `#C7D9B1` | Subtle secondary highlight |
| Secondary | `#2E312E` | Dark surfaces, UI elements |
| Muted | `#6B6E6A` | Secondary text and disabled elements |

## Usage guidance
- Keep the logo flat: no gradients, bevels, glows, or heavy shadows.
- Keep the lime accent sparse; it should be a cue, not the entire interface.
- Recommended font: Inter. Use system sans-serif fallbacks if Inter is unavailable.
- The SVG files are editable vector artwork. Check the mark at small sizes; the dot and stroke may need optical adjustment for 16–24 px.
- The tagline “A prompt. A moment. An action.” is optional and should not be embedded in the core logo.
